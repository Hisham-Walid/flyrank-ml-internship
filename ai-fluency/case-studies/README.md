# Framed portfolio cases

This folder contains the deliverable for **Frame It as Cases: Work That Speaks for Itself**.

- [`framed-cases.md`](framed-cases.md) is the submission document: voice card, two framed cases,
  bio, contact copy, and the required generic-line edit.
- [`interview-notes.md`](interview-notes.md) records the one-question-at-a-time Claude interview
  and the claim boundaries it exposed.
- [`claude-project-instructions.md`](claude-project-instructions.md) preserves the standing
  instructions configured in the portfolio Claude Project.

The cases use aggregate, repository-verifiable evidence only. They do not disclose client
identities, URLs, titles, raw queries, or private account information.
